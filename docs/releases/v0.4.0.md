# DML v0.4.0

发布日期：2026-10-26

## 内容

- 自动从 `JAVA_HOME`、`PATH`、Windows 注册表和常见厂商目录检测 Java，并读取版本、位数和可执行路径。
- 支持为每个实例自动匹配或手动选择 Java；当版本元数据声明 Java 主版本时，会在启动前检查兼容性。
- 解析 Mojang 新版 `arguments` 和旧版 `minecraftArguments`，处理 Windows、架构和功能规则，生成原版启动参数与类路径。
- 启动前按官方元数据提取 Windows natives，并拒绝越出实例目录的压缩包路径。
- 新增实例级最大内存、额外 JVM 参数、窗口尺寸和全屏设置。
- 启动 Java 子进程并实时捕获 stdout/stderr；记录最后启动时间、退出代码、累计游玩时长和实例内启动日志。
- 游戏运行期间，“启动游戏”按钮会变为“强制结束”；确认后可终止 Java 进程，并提示可能丢失未保存进度。
- 重排实例详情区域，加入纵向滚动条以适配较小窗口；日志页新增自动换行开关。

## 使用方式

下载 `DML-v0.4.0-win-x64.zip`，解压后运行 `dml.exe`；或者下载并运行 `dml_installer.exe` 完成当前用户安装。两个发布文件均提供同名的 `.sha256` 校验文件，且不需要预先安装 .NET。

启动 Minecraft 仍需安装版本元数据要求的 Java。DML 会自动检测已安装的 Java，也可以在实例的“启动设置”中手动选择 `java.exe`。

## 验证

- Release 配置构建通过，零警告、零错误。
- 19 项自动化测试全部通过，覆盖 Java 版本解析、启动参数、类路径、natives 提取、可靠下载、实例设置和累计游玩时长。
- 在 Windows 上使用 Java 25 启动已完整下载的 Minecraft 26.3 实例，确认创建 SDL/OpenGL 窗口并完成资源与声音初始化。
- 便携包与安装程序均由仓库中的 `scripts/Package-Release.ps1` 生成，并重新计算 SHA-256 校验值。

## 安全与数据边界

- 启动参数中的开发占位账号不包含真实账户凭据，也不提供绕过正版所有权验证的能力。
- 日志继续对常见令牌、Cookie、密码和授权码字段进行脱敏。
- natives 解压和版本文件路径必须位于实例目录内，路径穿越会被拒绝。
- 强制结束游戏需要二次确认；优先建议在游戏内正常退出，以免丢失未保存进度。

## 已知限制

- v0.4.0 尚未接入 Microsoft 正版登录。开发占位账号无法使用 Minecraft Services、Realms 或需要正版会话的在线功能；相关 401 日志属于预期行为。
- 界面一次只管理一个运行中的游戏实例，暂不支持同时启动多个实例。
- “导入实例”目前只复制所选目录，不验证其是否为完整 `.minecraft`，也不会自动识别可启动版本；导入后不能保证直接启动。
- 尚未完成 Java 17 / 21 历史版本、全屏模式和正常退出路径的完整人工兼容性矩阵。
- 软件未签名；首次运行安装器或程序时，Windows 可能显示 SmartScreen 提示。
