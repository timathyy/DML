# DML v0.2.0

发布日期：2026-10-24

## 内容

- 新增独立游戏实例模型，记录实例名称、Minecraft 版本、加载器、Java 路径、游戏目录、内存、分辨率和最后启动时间。
- 支持创建、复制、重命名、删除和导入实例；删除时将实例目录移入 Windows 回收站。
- 每个实例使用独立目录，并在复制和删除前校验管理目录边界，避免影响官方启动器或其他实例。
- 导入现有目录时复制全部内容到新的独立实例，原目录不会被修改。
- 新增实例列表、实例详情、磁盘可用空间提示和“打开实例文件夹”操作。
- 重做实例命名与删除确认窗口，并完善实例选中、悬停、深浅色主题和操作按钮样式。
- 统一设置、实例和日志页面的圆角滚动条；支持鼠标拖动和日志横向滚动，并避免与窗口缩放区域冲突。
- 增加实例文件系统隔离、复制与导入测试，以及界面主题颜色开发规范。

## 使用方式

下载 `DML-v0.2.0-win-x64.zip`，解压后运行 `dml.exe`；或者下载并运行 `dml_installer.exe` 完成安装。两个发布文件均提供同名的 `.sha256` 校验文件。

发布文件 SHA-256：

- `DML-v0.2.0-win-x64.zip`：`E1F97216692AB364DCBDE49F0CF0CB527DF892FA94BC8CF072DE1823E0A0B5D9`
- `dml_installer.exe`：`754B3619E224069CFA30231148A9E1FE80C23009E0F317DC5DE563AF85D2F93C`

实例数据默认保存在设置页所选游戏根目录的 `Instances` 子目录中。导入会复制源目录，而不是建立对源目录的引用。

## 已知限制

- 导入功能目前只检查所选目录是否存在，不验证它是否为有效的 `.minecraft`，也不会自动识别 Minecraft 版本或加载器。
- 尚未实现 Minecraft 版本发现与下载、Java 启动、Microsoft 账户登录、加载器安装或 Mod 管理。
- 软件未签名；首次运行安装器或程序时，Windows 可能显示 SmartScreen 提示。
- 安装版使用 Inno Setup 打包，尚未提供 MSIX 或自动更新功能。

## 校验发布文件

可在 PowerShell 中执行：

```powershell
Get-FileHash .\DML-v0.2.0-win-x64.zip -Algorithm SHA256
Get-FileHash .\dml_installer.exe -Algorithm SHA256
```

将输出结果与对应 `.sha256` 文件中的值比较。
