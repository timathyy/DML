# DML v0.1.0

发布日期：2026-10-23

## 内容

- 完成 DML 的 WPF/MVVM 项目骨架和依赖注入。
- 支持保存游戏根目录、下载并发数、代理地址和主题偏好。
- 提供浅色、深色、跟随 Windows 系统主题，以及自绘标题栏和现代化控件样式。
- 日志会自动掩盖常见令牌、Cookie、密码和授权码字段，并保留 14 天。

## 使用方式

下载 `DML-v0.1.0-win-x64.zip`，解压后运行 `dml.exe`；或者下载并运行 `dml_installer.exe` 完成安装。每个文件均附有同名的 `.sha256` 校验文件。

## 已知限制

- 尚未实现实例管理、游戏本体下载、Java 启动、Microsoft 账户登录、加载器或 Mod 管理。
- 软件未签名；首次运行时 Windows 可能显示 SmartScreen 警告。
- 安装版使用 Inno Setup 打包，尚未提供 MSIX 或自动更新功能。
