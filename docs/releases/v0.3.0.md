# DML v0.3.0

## 内容

- 创建实例时必须从 Mojang 官方 release / snapshot 中选择版本，确认后立即开始下载。
- 新增“下载”页面，集中显示实例、版本、进度、速率和剩余文件，并支持暂停、继续、重试与取消。
- 取消任务前会再次确认；确认后未完成实例及其文件将移入 Windows 回收站，避免保留不可用的半成品实例。
- 支持把版本 JSON、client JAR、适用于 Windows 的 libraries、natives 和 assets 安装到独立实例。
- 下载任务支持设置页定义的并发数、暂停、恢复、取消、自动重试和 HTTP Range 断点续传。
- 未完成文件以 `.dmlpart` 保留，任务状态随实例持久化；应用重启后可自动恢复下载，暂停状态则保持暂停。
- 每个文件都根据 Mojang 元数据校验大小与 SHA-1；只有校验通过才原子替换正式文件，损坏文件会重新下载。
- 版本清单缓存六小时；刷新失败时自动回退到本地缓存并在界面中明确提示。
- 新增下载百分比、平均速率、已完成/剩余文件数和错误原因展示。

## 安全与数据边界

- 所有下载地址来自 Mojang 官方版本元数据或 Minecraft 官方资源对象地址。
- 元数据声明的相对路径必须位于实例目录内，路径穿越会被拒绝。
- 各实例继续保持完全独立，不修改 Minecraft 官方启动器目录。

## 已知限制

- v0.3 只负责下载和校验，尚不能启动游戏；Java 检测与原版启动属于 v0.4。
- 当前只显示 release / snapshot，不在界面中展示历史 alpha / beta。
